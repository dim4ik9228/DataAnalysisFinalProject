# Підсумкові матеріали

Після завершення аналізу: звіт українською та презентація на 10–15 хвилин.
Для презентації рекомендовано Quarto reveal.js із нотатками доповідача.
Усі числа беруться з outputs/tables; графіки — з outputs/figures або з тих самих CSV.
На цьому етапі звіт і презентацію ще не створено.
