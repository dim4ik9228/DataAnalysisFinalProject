# План перевірок

Коли відповідні модулі реалізовано, додати перевірки:
- точних фільтрів Medu/Fedu й очікуваного N;
- базових категорій і формул моделі;
- відповідності еталонній таблиці з урахуванням округлення;
- детермінованості випадкових перевірок;
- повного запуску ноутбуків у чистих ядрах.

Архітектурні заглушки не видаються за виконаний аналіз.
