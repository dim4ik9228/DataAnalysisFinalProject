# Перевірки проєкту

P03: 36 цільових тестів, запуск `uv run --locked pytest -q`.

- test_data.py: 19 перевірок схеми, нульових оцінок, дублікатів, ID, ZIP, bootstrap, кешу, hash mismatch та неповного завантаження.
- test_preparation.py: 15 перевірок фільтра, перетину виключень, збереження нулів/дублікатів/порядку, еталонного N та CSV round-trip.
- test_data_workflow.py: 2 перевірки, що failed run не лишає prepared marker, зберігає діагностику й не експортує нову вибірку.

Тести використовують синтетичні fixtures і тимчасові каталоги; мережеві відповіді підставні. Окремо у P03 перевірено реальні файли, два кешовані запуски й повторне завантаження з порожнього кешу за tracked-хешами. Регресії не виконуються.

У майбутніх фазах додати тести матриць моделей, відтворення коефіцієнтів, випадкових перевірок і повного запуску після реалізації відповідної логіки.
