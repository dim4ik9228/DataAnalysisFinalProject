# Протокол реплікації

Дата чернетки: 2026-11-05. Статус: **чернетка до аналізу**.
Це не зовнішня пререєстрація. Зафіксувати версію комітом до оцінювання моделей.

## Мета

Відтворити OLS-моделі 1–4 (математика) і 7–10 (португальська) таблиці 8
Da (2025), далі окремо перевірити стійкість. Повний ML-пайплайн статті не
входить у початковий обсяг; беремо її опубліковані фінальні специфікації.

## Вихідна специфікація

- Ціль — G3, шкала 0–20.
- Medu/Fedu — категорії, базовий рівень 1 (початкова освіта), не безперервні роки.
- Для реплікації залишити Medu >= 1 і Fedu >= 1; нульові G3 залишити.
- Очікуване N статті: 390 (математика), 637 (португальська).
- M1/M7: C(Medu, reference=1) + C(Fedu, reference=1) + intercept.
- M2/M8: попередня + age + sex.
- M3/M9: попередня + school.
- M4/M10: попередня + guardian.
- Для sex/school/guardian узгодити базові категорії таблиці (M, MS, other).
- G1/G2 не включати як предиктори в точну реплікацію.
- Авторські числові результати ще потрібно перенести в data/reference
  з вказанням колонок і ручною перевіркою; це не наші результати.

## Відкриті питання до першого аналітичного запуску

1. Уточнити вид стандартних похибок таблиці 8: текст обговорює робастний
   inference, але примітка таблиці не задає конкретну HC-поправку.
   Порівнювати коефіцієнти й SE окремо; не заявляти точне відтворення SE без підстав.
2. Перевірити точні фільтри та кодування за статтею й першоджерелом даних.
3. Зафіксувати таблицю еталонних значень і фінальні допуски до оцінювання моделей.

## Критерії (пропозиція для фіксації до аналізу)

- Точне відтворення: збіг N та коефіцієнтів у межах точності друку статті.
  Допуск задається для кожного значення як половина одиниці останнього
  надрукованого розряду плюс мала числова похибка; SE порівнюються окремо.
- Стійкість: звітувати знак, величину та 95% CI для всіх наперед визначених
  варіантів; не вимагати автоматично значущості кожної підгрупи.
- Незбіг чисел не дорівнює спростуванню: спочатку аудит даних і специфікації.
- Для порівняння матері й батька — окремий Wald-тест рівності відповідних
  коефіцієнтів, а не порівняння двох p-value.

## План розширень

Кожен варіант змінює одну річ відносно відповідної базової моделі:
1. Включити Medu/Fedu = 0 (зберігши порівняння вища vs початкова освіта).
2. Виключити G3 = 0 без твердження, що причина нуля достеменно відома.
3. Освіта як порядкове число: окремий estimand «на один рівень».
4. Окремі школи з явним описом малих груп.
5. Додати studytime: умовна асоціація, без доказу причинного механізму.
6. Плацебо: додати незалежний випадковий шум із зафіксованим seed.

Перевірки другого предмета вже входять у реплікацію; не рахувати їх повторно
як нову незалежну вибірку. Учні можуть перетинатися між предметами.
Множинність перевірок, малі групи, самозвіти та невиміряні характеристики —
обов'язкові обмеження. Діагностика: залишки, Q-Q, VIF, впливові спостереження.
