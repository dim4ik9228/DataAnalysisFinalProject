## 2. Формат і вхідні матеріали

### Робочі формати

- Звіт: редагований reports/report.qmd → HTML і PDF. PDF через формат Typst у перевіреній версії Quarto; на початку реалізації підтвердити українські шрифти, формули, бібліографію й роботу без окремого TeX. Робочий орієнтир — 8–12 сторінок основного тексту плюс література/додатки; це наша редакційна ціль, не вимога курсу.
- Презентація: reports/slides.qmd → Quarto reveal.js, 1280×720, embed-resources:true. Основний показ — один самодостатній HTML, резерв — PDF слайдів. Графіки Plotly читають CSV, code echo:false, без даних, набраних у коді вручну.
- Нотатки — блоки .notes у QMD та окремий reports/speaker_notes.md для використання незалежно від speaker-view. Перевірити офлайн-показ графіків/формул і режим нотаток: self-contained HTML має обмеження для динамічних ресурсів. Не обіцяти offline speaker-view без реального тесту; незалежні нотатки — обов'язковий резерв.
- PPTX/DOCX не є обов'язковими виходами погодженого Quarto-маршруту. Якщо формат здачі потребує їх, зафіксувати конкретну вимогу до реалізації й додати окремий експорт/QA; не обіцяти автоматичної ідентичності layout у різних форматах.

Технічна основа перевірена в офіційній документації: [Quarto/Typst](https://quarto.org/docs/output-formats/typst.html), [показ/нотатки/друк reveal.js](https://quarto.org/docs/presentations/revealjs/presenting.html), [embed-resources та обмеження](https://quarto.org/docs/reference/formats/presentations/revealjs). Версії виконання визначаємо й фіксуємо під час P08.1, а не припускаємо за документацією.
