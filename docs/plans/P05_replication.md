### P05.4. Зіставлення з оригіналом — M

1. Для кожного з 68 estimate та 8 adjusted R² обчислити original, ours, absolute_difference, tolerance і match. Допуск із еталонів: половина останнього друкованого розряду + Decimal epsilon=1e-10; власні значення попередньо не округляти. N — точна рівність.
2. Join має перевіряти повне покриття еталонних ключів; відсутні/зайві терми не можуть мовчки зникнути. Власний intercept зберігати, але позначити як відсутній у публікації для порівняння.
3. Дати model-level complete match / partial match / mismatch за правилами протоколу. Повний глобальний збіг можливий лише для всіх восьми моделей. Інша вибірка/специфікація означає mismatch; SE виключені з числового вердикту. Явна деталізація глобального агрегування: будь-яка невідповідність вибірки/специфікації дає global mismatch; за валідних специфікацій усі complete дають global complete, усі mismatch — global mismatch, інші комбінації — global partial. Завжди показувати кількість моделей кожного статусу, щоб агрегат не приховував локальних незбігів. Це уточнення агрегації до оцінювання, без зміни предметних критеріїв/допусків.
4. Для 68 SE показати відхилення й числовий збіг окремо для кожного covariance. Статус авторського методу завжди not_identified до нових первинних доказів; збіг чисел не доводить відтворення авторського inference. Авторські p/CI та зірочки не реконструювати як точні тести.
5. Незбіги дослідити у фіксованому порядку: source/хеш → рядки/N → категорії/константа → формула/терми → точність друку → covariance для SE. Нові пошукові варіанти не запускати для «покращення» збігу; зберігати невирішені розбіжності.

**Вихід/приймання:** перевірка кожної опублікованої клітинки, модельний/глобальний вердикт та журнал розбіжностей. Виконавці: координатор, незалежна звірка reviewer.

### P05.5. Основні H1/H2 та змістовий висновок — S

1. H1: два двобічні тести Medu_4=0 у M4/M10, основний HC3; Holm лише всередині цих двох тестів.
2. H2: прямий контраст Medu_4−Fedu_4, SE із повної covariance з урахуванням коваріації, 95% normal CI, Wald chi-square з 1 df. Окреме сімейство Holm із двох предметних тестів.
3. Експортувати raw/adjusted p, family, знак, estimate/contrast, SE, CI та вердикт. Очікування підтримано за додатного знака й p_Holm<0.05; протилежний значущий знак — свідчення проти; решта — недостатньо доказів. Звичайні 95% CI не називати одночасними або Holm-adjusted CI.
4. «В обох предметах» дозволено лише за двох підтверджень. Незначущість Fedu не означає Fedu=0; різниця значущості не доводить різницю коефіцієнтів. Другий предмет не є незалежною новою вибіркою. H3 залишається у P06.

**Вихід/приймання:** 4 рядки основних тестів і три окремі типи висновків; без причинних інтерпретацій. Виконавець: statistical_analyst, аудит reviewer.
