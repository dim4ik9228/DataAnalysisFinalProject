## Пошук і докази

[Журнал](evidence/literature_followup/search_log.md) містить точні запити, URL, індекси, дати й рішення. [Europe PMC](https://www.ebi.ac.uk/europepmc/webservices/rest/MED/40180962/citations?format=json) повернув hitCount0; [OpenAlex](https://api.openalex.org/works?filter=cites%3AW4409150759&per_page=25) — count3, усі на одній сторінці. Це різні покриття. 42 outgoing references Da не є42 цитуваннями оригіналу. Crossref is-referenced-by-count не замінює повного cited-by реєстру. Google Scholar, Scopus і Web of Science не заявляються перевіреними.

Офіційні API JSON і короткі вибрані reference-докази/нотатки мають [маніфест SHA-256](evidence/literature_followup/manifest.json); [машинний підсумок](evidence/literature_followup/summary.json) розділяє первинно перевірені цитування, метадані й змістовні перевірки. Повні статті не копіювали. Publisher JSON містять хеш отриманого HTML і короткі докази; маніфест хешує локальні JSON. PDF-конфлікт є нотаткою вебчитання, без локального PDF.

Навіть із LF03 як цитуванням за метаданими2<3. Низька тематична релевантність LF01 не дозволяє називати його реплікацією. [Вимога курсу](course_requirements.md) відкрита; узгодження заміни з викладачем не проводилося.

## Зіставлення з P02

Наші умовні асоціації UCI зіставляються насамперед із Da. Тематичні Davis-Kean/Dubow/Waters з P02 пояснюють можливі сімейні механізми й обмеження вимірювання; інші популяції, вік, дизайн і шкали не дозволяють об'єднувати ефекти або називати наш результат реплікацією їхніх оцінок. LF01–LF03 не дають підстав посилювати причинні висновки чи змінювати моделі.
